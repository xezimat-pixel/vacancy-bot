# vacancy-bot

Телеграм бот: читает каналы с вакансиями, ИИ отбирает подходящие под профиль, пишет отклик
и присылает карточку в нужную тему группы вместе с подходящими работами из портфолио.

Запускается на GitHub Actions каждые 10 минут (`.github/workflows/vacancy-bot.yml`).
Настройки: `config.yaml`. Ключи хранятся в секретах репозитория, состояние зашифровано в `state.enc`.
